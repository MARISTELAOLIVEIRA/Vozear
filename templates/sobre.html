Sobre

O VOZEAR é um projeto desenvolvido por mim, Profª Maristela Oliveira, e nasceu da necessidade real de tornar o conteúdo digital mais acessível, especialmente para alunos com deficiência visual, dificuldades de leitura e (/ou) escrita ou alguma neurodivergência. Foi desenvolvido em Python com o framework web Flask e banco de dados MySQL.

O aluno que utiliza ledores de tela, não encontrará dificuldades em acessar o conteúdo do site, pois ele foi projetado para ser totalmente compatível com tecnologias assistivas. Além disso, o sistema é responsivo, garantindo uma experiência de usuário consistente em dispositivos móveis e desktops. As pessoas sensíveis à luz intensa ou que preferem uma interface mais escura podem ativar o modo escuro, proporcionando uma experiência visual mais confortável.

A aplicação utiliza as tecnologias Microsoft Azure:

✔️ Serviço de Aplicativo com suporte a múltiplas linguagens de programação (servidor Canada Central);
✔️ Servidor flexível do Banco de Dados do Azure para MySQL (servidor Canada East);
✔️ API de síntese de voz, com vozes naturais e de alta qualidade;
✔️ Inteligência artificial Azure Computer Vision (servidor East US), um serviço que analisa e descreve imagens automaticamente. Isso permite que o sistema interprete imagens contidas em PDFs ou enviadas separadamente, gerando uma descrição em texto que é posteriormente convertida em áudio.

Entre os recursos disponíveis, o usuário pode:

✔️ Inserir texto manualmente;
✔️ Enviar arquivos PDF com ou sem imagens;
✔️ Enviar imagens que serão descritas automaticamente por IA;
✔️ Usar a própria voz ativando o microfone (gerando um arquivo de texto);
✔️ Baixar o texto gerado a partir do áudio;
✔️ Inserir uma URL para que o sistema leia o conteúdo da página;
✔️ Escolher diferentes vozes;
✔️ Ajustar a velocidade da leitura;
✔️ Ouvir o áudio gerado diretamente no navegador;
✔️ Fazer o download dos arquivos gerados, disponível por 10 minutos após a conversão, após esse período, os arquivos são removidos do servidor automaticamente para economizar espaço.
